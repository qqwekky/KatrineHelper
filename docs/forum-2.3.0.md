# Katrine Helper 2.3.0 — статті з /ask і перевірка біндів

**Із довідника — одразу до оформлення.** Знайшли потрібну статтю через `/ask`? Натисніть **«Использовать»** біля неї. Для статті з рівнем розшуку відкриється форма розшуку, для статті зі штрафом — форма штрафу. Стаття вже буде вибрана. Якщо підозрюваного вже обрано й він онлайн, одразу побачите його нік та ID. Інакше можна вибрати гравця зі списку поруч або ввести ID вручну. Перед відправленням перевірте дані й натисніть **«Подтвердить»**.

**Бінд можна перевірити ще до збереження.** Натисніть **«Проверить»** під текстом у редакторі. Побачите, який рядок спрацює першим і скільки часу мине до наступного. Наприклад, із паузою 1,5 секунди попередній перегляд виглядатиме так:

    0,0 с   /me достал блокнот.
    1,5 с   /do Блокнот в руке.

Перевірка враховує паузи бінда, антифлуд і мітки `{wait N}`. Якщо команді бракує ID, мітка `{arg}` порожня або в тексті є невідома мітка, редактор підсвітить конкретний рядок. Можна одразу виправити його й перевірити ще раз. Усе відбувається локально, без відправлення команд у чат.

Оновлення доступне через автооновлення хелпера. [Katrine Helper на GitHub](https://github.com/qqwekky/KatrineHelper)
